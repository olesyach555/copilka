# Kopilka — Семейный финансовый помощник

**Kopilka** — это настольное C#‑приложение для семейного учета доходов, расходов и управления бюджетом с поддержкой нескольких пользователей и ролей.

## Возможности

- Учет доходов и расходов по категориям
- Ведение нескольких счетов (карт, наличных и др.)
- Аналитика баланса, отчеты по пользователям и категориям
- Регистрация и авторизация пользователей, роли пользователь/администратор
- Безопасное хранение данных в SQL (Entity Framework)
- Гибкая настройка категорий и типов счетов
- Поддержка совместного семейного бюджета

## Структура решения

```
/src/Kopilka.FinanceManager    — UI (WinForms или WPF)
/src/Kopilka.DataAccess        — Слой доступа к данным (DAL, контекст EF, миграции)
/src/Kopilka.BusinessLogic     — Бизнес-логика
/src/Kopilka.Shared            — Общие классы, утилиты
/tests/Kopilka.Tests           — Юнит-тесты
/docs                          — Документация (структура БД, схемы)
/README.md                     — Описание и инструкция
```

## Установка и запуск

1. Установите [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download) и Visual Studio Community 2022+.
2. Клонируйте репозиторий и откройте `Kopilka.sln` в Visual Studio.
3. Проведите миграции базы данных командой в **Package Manager Console**:
   ```
   Update-Database
   ```
4. Соберите и запустите проект `Kopilka.FinanceManager`.

## Использование

- При первом запуске администратор может создать пользователей и категории.
- Через UI добавляйте счета, доходы и расходы, группируйте по категориям.
- Администратор ведет учет пользователей, настройки, просмотры статистики.

## Архитектура Базы Данных

- Пользователь (User): Id, Login, PasswordHash, Role
- Счет (Account): Id, UserId, Type, Balance, Name, Currency
- Категория (Category): Id, Name, Type (Expense/Income), Description
- Транзакция (Transaction): Id, AccountId, CategoryId, Amount, Date, Comment
