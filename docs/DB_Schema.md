# Архитектура Базы Данных "Копилка"

Этот документ описывает структуру таблиц в базе данных SQL для приложения "Копилка".

## Таблица: Users (Пользователи)

Хранит информацию об учетных записях пользователей.

| Поле          | Тип           | Описание                                      |
|---------------|---------------|-----------------------------------------------|
| `Id`          | `INT`         | Первичный ключ, уникальный идентификатор      |
| `Login`       | `NVARCHAR(50)`| Логин пользователя для входа в систему        |
| `PasswordHash`| `NVARCHAR(256)`| Хеш пароля для безопасного хранения           |
| `Role`        | `NVARCHAR(20)`| Роль пользователя (например, 'Admin', 'User') |

## Таблица: Accounts (Счета)

Хранит информацию о финансовых счетах пользователей.

| Поле      | Тип           | Описание                                           |
|-----------|---------------|----------------------------------------------------|
| `Id`      | `INT`         | Первичный ключ                                     |
| `UserId`  | `INT`         | Внешний ключ, связывающий счет с пользователем     |
| `Type`    | `NVARCHAR(50)`| Тип счета (например, 'Карта', 'Наличные', 'Депозит')|
| `Balance` | `DECIMAL(18,2)`| Текущий баланс на счете                           |
| `Name`    | `NVARCHAR(100)`| Название счета                                     |
| `Currency`| `NVARCHAR(10)` | Валюта счета (например, 'RUB', 'USD')              |

## Таблица: Categories (Категории)

Справочник категорий для доходов и расходов.

| Поле        | Тип           | Описание                                        |
|-------------|---------------|-------------------------------------------------|
| `Id`        | `INT`         | Первичный ключ                                  |
| `Name`      | `NVARCHAR(100)`| Название категории                              |
| `Type`      | `NVARCHAR(20)`| Тип категории ('Expense' или 'Income')          |
| `Description`| `NVARCHAR(255)`| Краткое описание категории (необязательно)      |

## Таблица: Transactions (Транзакции)

Хранит информацию о всех финансовых операциях.

| Поле         | Тип           | Описание                                           |
|--------------|---------------|----------------------------------------------------|
| `Id`         | `INT`         | Первичный ключ                                     |
| `AccountId`  | `INT`         | Внешний ключ, связывающий транзакцию со счетом     |
| `CategoryId` | `INT`         | Внешний ключ, связывающий транзакцию с категорией  |
| `Amount`     | `DECIMAL(18,2)`| Сумма транзакции                                   |
| `Date`       | `DATETIME`    | Дата и время проведения транзакции                 |
| `Comment`    | `NVARCHAR(255)`| Комментарий к транзакции (необязательно)           |

## Связи между таблицами

- `Users` (1) -> `Accounts` (M) : Один пользователь может иметь много счетов.
- `Accounts` (1) -> `Transactions` (M) : Один счет может иметь много транзакций.
- `Categories` (1) -> `Transactions` (M) : Одна категория может быть использована во многих транзакциях.
