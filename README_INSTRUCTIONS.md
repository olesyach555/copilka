# Инструкция по запуску проекта Kopilka

Проект «Копилка» представляет собой настольное WPF-приложение для семейного учета финансов.

## Структура решения
- **Kopilka.Shared**: Модели данных.
- **Kopilka.DataAccess**: Контекст базы данных и миграции (SQLite).
- **Kopilka.BusinessLogic**: Сервисы и ViewModels (MVVM).
- **Kopilka.FinanceManager**: Пользовательский интерфейс (WPF).
- **Kopilka.Migrator**: Консольное приложение для управления базой данных в средах без SDK Windows Desktop.

## Требования
- .NET 8.0 SDK

## Шаги для запуска (в Visual Studio / Rider):

1. **Создание базы данных**:
   Откройте **Консоль диспетчера пакетов** (Package Manager Console) и выполните:
   ```powershell
   Update-Database -Project Kopilka.DataAccess -StartupProject Kopilka.FinanceManager
   ```
   Или через dotnet CLI:
   ```bash
   dotnet ef database update --project src/Kopilka.DataAccess/Kopilka.DataAccess.csproj --startup-project src/Kopilka.Migrator/Kopilka.Migrator.csproj
   ```

2. **Запуск приложения**:
   Установите проект `Kopilka.FinanceManager` как стартовый и запустите (F5).

## Основные возможности:
- **Вход и Регистрация**: При первом запуске создайте аккаунт.
- **Журнал**: Учет доходов и расходов с фильтрацией по датам.
- **Графики**: Визуализация финансовой активности за выбранный период.
- **Долги**: Учет займов с расчетом графиков платежей (аннуитетных и дифференцированных).
- **Цели**: Постановка финансовых целей с отслеживанием прогресса.
- **Напоминания**: Уведомления о предстоящих платежах и покупках.
- **Семейный доступ**: Управление пользователями семьи и общим паролем.

## Технические особенности:
- Использован **CommunityToolkit.Mvvm** для реализации MVVM.
- **SQLite** используется в качестве БД, поле `decimal` мапится в `TEXT`.
- Расчет суммы (`SumAsync`) реализован через приведение к `double` для совместимости с SQLite.
- Внедрение зависимостей (DI) реализовано **вручную** в `App.xaml.cs`.
